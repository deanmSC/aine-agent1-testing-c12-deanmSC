# App Removed

This app has been removed from the repository as requested.

## What Was Here

This directory previously contained a **Team Task Tracker** app - a simple task management tool for small teams that allowed users to:
- View and manage tasks in a table
- Add, edit, and delete tasks
- Mark tasks as complete or pending
- Search and filter tasks
- See summary statistics

## Why It Was Removed

The app was removed per analyst request on 2026-10-12.

## What Happened to the Data

Since this was a static web app that stored data in the browser's localStorage, no central data existed. Each user's tasks were stored locally in their own browser only.

## Need to Restore It?

If you need to restore this app, you can find it in the git history before this removal. Look for the commit titled "Restore point: Team Task Tracker app before removal" or check the pull request that removed it.
